# New Starter IT Setup Checklist

## 1. Purpose

What a new Zuqah Technologies employee receives, when, and what they need to do themselves.
This document is written for the new starter; the hiring manager's own checklist
lives in the HR portal.

## 2. Before the first day

The hiring manager raises an onboarding request at least **10 business days**
before the start date. Requests inside 5 business days cannot guarantee equipment
on day one, because delivery alone takes five to seven days.

By the start date the following exist:

- A Zuqah Technologies account and email address
- A laptop, configured and shipped to the delivery address
- Membership of the practice's core groups
- A Service Desk profile

## 3. Day one

Setting up takes about **45 minutes**. Do it in this order — several steps depend
on the one before.

1. **Unbox and power on.** Connect to any internet connection.
2. **Sign in** with the temporary credentials sent to your personal email.
3. **Set a password** meeting the Password and Multi-Factor Authentication
   Standard. Fourteen characters minimum; no complexity rules.
4. **Register two MFA methods.** Two, not one — losing a single registered device
   is the most common cause of a lockout in the first month.
5. **Wait for the initial policy sync.** Ten to fifteen minutes, during which the
   laptop applies encryption, endpoint protection and the software baseline. Do
   not restart during this step.
6. **Connect the VPN** and confirm it reaches an internal site. See the Remote
   Access and VPN Policy, section 3.
7. **Open Zuqah Technologies Mail and Zuqah Technologies Teams.** Both are published directly and do
   not need the VPN.
8. **Install what you need** from the Software Portal.

## 4. What arrives automatically

| Item | Timing |
| --- | --- |
| Laptop, charger, travel adapter | Before the start date |
| Zuqah Technologies account and email | Before the start date |
| Core application access | Before the start date |
| Docking station and monitor, if requested | Within the first week |
| Corporate card, where the role requires one | Within two weeks |

## 5. What you request yourself

Access beyond the baseline is deliberately not granted in advance, because the
right set depends on the engagement. Once you know what you need, request it in
the IT portal:

- Client-specific systems and environments
- Practice tools outside the Software Portal
- Additional monitors beyond the first
- Anything requiring elevated permissions, per the Privileged Access standard

## 6. First-week checklist

- Complete security awareness training — assigned automatically, due within 14 days
- Read the Code of Conduct and confirm you have done so
- Install the password manager from the Software Portal
- Confirm your emergency contact in the HR portal
- Book a Service Desk drop-in if anything is unclear

## 7. Common first-week problems

**The temporary password does not work.** It expires after 72 hours. Contact the
Service Desk for a new one; this is routine and does not need justification.

**The laptop has not arrived.** Check with your hiring manager first — the
delivery address is set on the onboarding request and an incorrect address is the
usual cause. If the address was correct, raise a ticket; a new starter unable to
work is treated as a P3 incident rather than a routine request, per the Incident
Priority and Service Level Standard.

**An application says access denied.** Most likely it is outside the baseline and
needs requesting. Check section 5 before raising a ticket.

**The VPN will not connect on the first attempt.** The first connection runs a
posture check and may install pending updates, which can take several minutes.
Allow it to finish and retry once before raising anything.

## 8. Returning equipment

If you leave Zuqah Technologies, all equipment is returned by the final working day. See the
Laptop Refresh and Hardware Standards for the return process.
